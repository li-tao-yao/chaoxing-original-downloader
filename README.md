# 超星原始课件下载

在超星网页端打开课程或章节，点击右下角的「课件下载」。可以逐份下载，也可以勾选多份已开放下载的文档，再点击「下载勾选」。

例如，教师上传的 `引言.pptx` 会保存为 `引言.pptx`。脚本支持 PPT、PPTX 和 PDF，并在保存前检查文件头。仅供预览的章节附件会被跳过。

## 安装

在浏览器安装 Tampermonkey，打开 [Greasy Fork 安装页](https://greasyfork.org/zh-CN/scripts/607172)，点击「安装此脚本」并在油猴中确认，然后刷新超星课程页。使用旧版脚本的用户请先在油猴管理面板停用旧版，以免页面同时出现两个面板。

## 来源与许可

此版本基于 [Fiatnorm 的 Chaoxing PDF Dumper 0.6.1](https://github.com/Fiatnorm/Chaoxing-PDF-Dumper) 修改。沿用课程和章节选择面板，增加 PPT/PPTX 原格式保存、下载前的文件头检查，并按照文档组件的下载设置筛选课件。
